# Frontend — Investment Dashboard (React + Vite + Tailwind)

Populated by task 08 (`../tasks/08-frontend-scaffold.md`): Vite + React + TypeScript + Tailwind,
React Query, Recharts, and a typed API client pointing at the FastAPI backend via

## Run (after task 08 scaffolds it)

```bash
npm install
npm run dev        # http://localhost:5173
```
